Researcher's Desk

Chloe's view of the same intake material tracked on the Sources page — organized as she'd work it: Updates for anything not yet looked at, Pending for anything still needing attention (an automated pass actively running, or one that finished and left something for you to decide), Processed for everything fully settled (matched or rejected). Adding something here or on Sources is the same action either way — one shared pile, three views into it.

About This Desk
Chloe has two jobs. Outbound: checking the Master Site List for new mentions or sales of the artist's work, logged into New Finds for your review. Inbound: gathering provenance research, exhibition history, and raw material into the holding folder for Khalo to sort through. Either way she doesn't touch the live catalogue directly — a human always reviews first. Run her from a Claude Code session (the researcher skill) any time, or chat with her from the Agents page.
New Finds

Approve moves it toward Khalo's proper matching/citation work; Reject keeps it in the CR Archive as a record of what was checked and ruled out; Trash removes it outright, since a large reject pile nobody revisits isn't useful.

External Archive
Indexed, not uploaded — the raw masters never leave the drive. For large raw shoots (e.g. 500MB–4GB TIFF masters from a photographer, spread across many folders), scripts/archive_indexer.py runs locally on whatever machine has the drive attached and records just the filename/size/type of everything in a folder into the table below — no image bytes are ever uploaded. When one specific file is actually needed for a work, the same script converts just that file to JPG and uploads only the JPG, the same way the dropzone above does. This site and no Claude Code session can read the drive directly — the script is the only bridge, and it only ever runs when someone at the studio runs it.
Indexed Archives
Read-only — populated by archive_indexer.py running locally, not from this page. "Converted" means a JPG has already been pulled in and is sitting in Updates/Archive above.
